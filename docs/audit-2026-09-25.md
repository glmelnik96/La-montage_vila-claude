# Audit 2026-09-25: open findings

A review of all scripts against SKILL.md and the references found about 60 issues. The ones
that could damage a project or silently give a wrong result were fixed that day:
- the bridge option pass-through and the triple retry;
- cloud ASR failures turning into empty text;
- the `ripplecut` state path and its In/Out parse error;
- `assemble` able to empty its source;
- the `snapplan` edges crossing;
- the `planpreview` seek;
- the `preflight` gate;
- `pr.mjs` recovering after a timeout;
- `blockcut` re-runs.

What is left is listed below. When you touch one of these files, fix its line here and
delete the entry.

## Worth doing next
- **`scripts/render.mjs`.** Rendering from a script was hand-written in four jobs (frames,
  AIFF, whole sequence). One tool should cover it: a throwaway clone, In/Out or
  `ENCODE_ENTIRE`, the JPEG or AIFF preset, wait until the file is stable, delete the clone in
  a separate call. The JPEG preset appends `0` to the name. It needs live testing.
- **A camera-sync tool.** The method is in `references/multicam-sync.md`; the job's code was
  one-off. Generalize it the next time a multicam sync comes up (the rule is to generalize
  once a tool has been useful twice).
- **`assemble.mjs` cannot place audio-only items.** It takes its source from V1 clips and
  looks the result up on a video track. Placing a recorder WAV needs:
  - an audio-track row field;
  - in/out set in ticks on the placed item (29.97 fps snapping);
  - a done-check in ticks.

## Risks
- `rearrange.mjs`:
  - re-running `razor`/`lift` after `place` has moved pieces lifts kept pieces;
  - `park` is not checked against the sequence end (5000 fails past 83 min).
- `placestills.mjs`: re-placing one missing still on a busy track eats the next still's
  head. "Re-running is safe" holds only on an empty track.
- `placestills.mjs`, `ripplecut.mjs`, `rearrange.mjs` turn seconds into `Time` without the
  +1 ms nudge (uncertain whether those setters round down).
- `trackorder.mjs` reads every clip of every sequence in one call; on a big project that may
  outlast the timeout.
- `checkreframe.mjs`, `shots.mjs probe`: ffmpeg clamps a crop that runs past the image, so
  black edges in Premiere show as a clean frame on the sheet. Overlay the scaled source on a
  black 1080×1920 canvas instead.
- `checkreframe.mjs` finds Motion/Scale/Position by English display name, so a localized
  Premiere breaks it. Use `matchName` `AE.ADBE Motion`.
- `vframe.mjs`, `checkreframe.mjs`: the 1080×1920 frame is hard-coded.
- `slidetrack.py`, `scrollviews.py` assume 16:9 pages. Frames are now normalised to
  1920×1080.
- `cloudtr.mjs`: on a clip that is mostly silence (raw takes with waits), the speech
  threshold falls below the room tone and chunk edges stop being pauses. Estimate speech from
  the 90th–95th percentile and keep the threshold ≥ 6 dB above the floor.
- `cloudtr.mjs --pieces`: the names prompt goes first and the previous phrase last. If the
  server keeps only the tail of a long prompt, the names are cut (uncertain).
- `mixdown.mjs`: every input sits on one command line, which hits the Windows 32 767-character
  limit at about 180 clips. Use a filter script and batches.
- `audio.mjs`, `scan.mjs` (and `edgecheck`, `snapplan`) downmix to mono: a voice on one
  channel reads 6 dB low. Add a channel option.
- `edgetext.mjs` prints any segment touching the window whole, which hides a blade inside a
  segment. The joins inside a block are never printed.
- `edgecheck.mjs`: four consecutive 20 ms windows are needed to count as speech, so a short
  word at the blade («и», «а») is invisible.
- `splicecheck.py`, `transcribe_mixed.py`: no `--device`, no CPU fallback.
  `transcribe_mixed.py` decodes the whole source once per clip entry.
- `rewin.py`: Russian is hard-coded; the model is the 4th argument (default `medium`, CPU).
- `markercolors.mjs`: exits 0 on a host error.
- `mogrtcard.py`: never checks that exactly one text blob was patched, so a template without
  `mTextParam` gives cards with the stock text.
